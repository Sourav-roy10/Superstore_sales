# 📊 Superstore Sales & Profitability Dashboard

An interactive **Power BI dashboard** analyzing Superstore sales, profitability, discounts, product categories, and daily discount trends. The project demonstrates an end-to-end analytics workflow using **Python, Excel, and Power BI**.

## 🛠 Tools Used

- **Python (Pandas)** – Data cleaning, preprocessing, and validation
- **Excel** – Data understanding, exploration, and preparation
- **Power BI** – Data modeling, DAX calculations, KPI creation, and dashboard visualization

## 📌 Dashboard Highlights

- **10K+ orders** analyzed
- **$25.47M total sales**
- **$1.26M loss** identified
- Analyzed **profit by category and discount range**
- Compared **sales vs. profit** across product categories
- Examined **quantity distribution** by category
- Analyzed **daily discount patterns**

## 🔑 Key Insights

- The dashboard highlights a significant gap between **sales and profitability**.
- Higher discount ranges are associated with **substantial negative profit**.
- Technology generates the highest sales among the analyzed categories but still shows negative profit.
- Profitability varies significantly across discount ranges, providing opportunities for **discount and pricing optimization**.

## 🎯 Business Objective

The project focuses on identifying **profitability issues and discount-related losses** to support better pricing, discount, and product-category decisions.

## 👨‍💻 Project Workflow

**Python → Excel → Power BI**

Data Cleaning → Data Understanding → Data Modeling → DAX → KPI Analysis → Interactive Dashboard
